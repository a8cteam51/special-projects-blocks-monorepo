# Changelog

All notable changes to this project will be documented in this file.

## 0.1.2

### Fixed

- Border settings now show in the editor and are output on the front end. The block's border support is now declared as `__experimentalBorder`, the key WordPress reads (#246).

## 0.1.1

### Removed

- Self-update mechanism. Updates are now installed manually from GitHub releases.

## 0.1.0

### Added

- Adds a download button to VideoPress videos in a post.
